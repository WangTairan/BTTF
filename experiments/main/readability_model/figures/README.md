# Research figures

`plot_three_llm_consensus_sensitivity.py` reproduces the feature-budget figure
reported in the paper from the fixed three-causal-LM consensus ranking. It does
not extract features, change benchmark data, or alter a frozen model. The PDF
is written to `figures/publication/feature_count_sensitivity_full_model.pdf`
and its plotted values to the matching CSV under `figures/data/`.
