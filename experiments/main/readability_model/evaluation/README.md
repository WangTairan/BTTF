# Main-model evaluation

Fixed-feature evaluation lives here: pooled cross-validation,
leave-one-dataset-out, pretrained-model refits, family ablations, bootstrap
uncertainty, and controlled-interference scoring. The final 11-feature and
18-feature predecessor ablations have distinct entry points. These scripts
read retained feature specifications and do not search for a new feature set.
Run from the repository root; generated reports belong in `results/`.
