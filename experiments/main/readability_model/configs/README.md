# Model specifications and evidence

The two configuration files define the retained publication models:

- `consensus11_6dataset_three_llm_opencoder_jina.json`: final model;
- `consensus18_6dataset_sampled_margin.json`: embedding-only predecessor.

`evidence/` contains the consensus rankings, robustness table, bootstrap
intervals, and selected-rank records supporting the paper. Fitted coefficients
and preprocessing statistics are stored under `frozen_models/`.
