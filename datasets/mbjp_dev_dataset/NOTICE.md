# MBJP development set

The MBJP problem statements derive from MBXP, released by Ben Athiwaratkun and
coauthors in *Multi-lingual Evaluation of Code Generation Models*:
<https://github.com/amazon-science/mxeval>.

The upstream **MBXP data** are licensed under CC BY 4.0. This is distinct from
the mxeval evaluation code's Apache-2.0 license:
<https://github.com/amazon-science/mxeval/blob/main/data/mbxp/LICENSE>.
The full data-license text is in
[`CC-BY-4.0.txt`](../../licenses/third_party/CC-BY-4.0.txt).

`readability_dataset.json` is the 17-program development set curated for this
study, not the complete upstream MBJP release. It combines MBJP-derived problem
statements, generated Java implementations, and this study's human readability
ratings. These additions and the selection are modifications to the upstream
benchmark material. This notice does not assign a new license to the study's
original contributions or replace the upstream data license.
